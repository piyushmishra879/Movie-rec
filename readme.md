# 🎬 Movie Recommendation System

A content-based movie recommendation system built using **Machine Learning**, **Streamlit**, and **Python**.

## 🚀 Features
- Recommends similar movies
- Fast response using TF-IDF & cosine similarity
- Interactive Streamlit UI

## 🛠 Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas, NumPy

## ▶️ How to Run
```bash
conda create -n movie_reco python=3.10
conda activate movie_reco
pip install -r requirements.txt
streamlit run app.py
